# Ollama 임베딩 모델 비교: mxbai-embed-large vs bge-m3

2026-05-17, DeepSeek Chat + Ollama 로컬 임베딩으로 4가지 시나리오 실행 결과.

## 테스트 환경

| 항목 | 값 |
|------|-----|
| LLM | DeepSeek Chat (deepseek-chat) |
| Ollama 서버 | localhost:11434 |
| 시나리오 수 | 4 (LLM only / 키워드 RAG / Emb+LLM / Full RAG) |
| 질문 수 | 3 |
| 지식 베이스 | 5개 한글 문서 (환불, 배송, VIP, 개인정보, 쿠폰) |

## 비교 모델

| 모델 | 차원 | 크기 | 특징 |
|------|:---:|------|------|
| `mxbai-embed-large:335m` | 1024 | ~335M params | 다국어 지원, 경량 |
| `bge-m3:567m` | 1024 | ~567M params | 100+ 언어, MIRACL 벤치마크 상위권 |

## 의도 분류 정확도 (시나리오 3: Embedding + LLM)

질문을 사전 정의된 5개 주제(refund, shipping, membership, privacy, promotion) 중 하나로 분류한다.

| 질문 | 정답 | mxbai-embed-large | bge-m3 |
|---|---|---|---|
| VIP 멤버십 혜택이 무엇인가요? | membership | membership 0.73 ✅ | membership **0.77** ✅ |
| 돈을 돌려받고 싶어요 | refund | **promotion** 0.47 ❌ | **refund** 0.65 ✅ |
| 개인정보는 얼마나 보관되나요? | privacy | **promotion** 0.58 ❌ | **privacy** 0.57 ✅ |

- `mxbai-embed-large`: 1/3 정확 (33%)
- **`bge-m3`: 3/3 정확 (100%)**

"돈을 돌려받고 싶어요"에서 "돌려받고"와 "refund"의 의미적 연결, "개인정보"와 "privacy"의 연결이 `bge-m3`에서 훨씬 정확하게 포착되었다.

## 결론

1. **키워드 검색(시나리오 2)의 근본적 한계**: 한국어는 조사("은/는/이/가")와 어미 변화로 키워드 불일치가 쉽게 발생한다. "환불" vs "돌려받고", "개인정보" vs "개인정보는" 모두 매칭 실패.

2. **의도 분류 정확도는 모델에 크게 의존**: `mxbai-embed-large`(335M)는 한글 질문 → 영어 주제 간 의미 연결이 약했지만, `bge-m3`(567M)는 3개 모두 정확히 분류했다.

3. **Full RAG가 가장 신뢰할 수 있는 방식**: 의도 분류 없이 질문과 문서 전문 간의 직접 유사도 비교만으로도 정답 문서를 찾는다. `bge-m3` 기준 3개 질문 모두 1위로 정답 문서 검색.

4. **임베딩 모델 선택이 RAG 성능을 좌우한다**: 동일한 파이프라인에서 `bge-m3`로 교체만으로 의도 분류 33% → 100%, 문서 검색 1위 정확도 33% → 100%로 개선되었다.

| 상황 | 추천 모델 |
|---|---|
| 영문 전용, 빠른 응답 | `all-MiniLM-L6-v2` (384d, SentenceTransformers) |
| 다국어, 경량 | `mxbai-embed-large:335m` (1024d, Ollama) |
| 다국어, 높은 정확도 | `bge-m3:567m` (1024d, Ollama) |
